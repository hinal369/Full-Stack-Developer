Content-Box vs Border-Box

Content-Box

In content-box, the width and height only include the content. The padding and border are added to the total size of the element.

This is a box with content-box sizing.
h2>Border-Box

In border-box, the width and height include the content, padding, and border. This means that the total size of the element is determined by the width and height properties, and the content area is adjusted to fit within those dimensions.

This is a box with border-box sizing.
