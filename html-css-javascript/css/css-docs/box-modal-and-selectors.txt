# Box Modal
 - It's important to remember that everything displayed by CSS is a box, 
 even if it's just some text, or has a border-radius that makes it look like a circle.
 - It's important to remember that intrinsic sizing is the browser's default behavior, 
 and it usually provides much more flexibility than extrinsic sizing.
 - In content-box, the width and height only include the content. The padding and border are added to the total size of the element.
 - In border-box, the width and height include the content, padding, and border. 
 This means that the total size of the element is determined by the width and height properties, 
 and the content area is adjusted to fit within those dimensions.

# Selectors
  1. What is the difference between the below: first-of-type, p:nth-child(1), p:nth-of-type(1) & first-child?
    - Group 1: The Strict First-Borns (:first-child and :nth-child(1))  
    These two selectors do the exact same thing. They are interchangeable.
    When you write article p:first-child (or nth-child(1)), you are telling the browser:
    1. Look inside the <article>.
    2. Find the very first element inside it.
    3. If and only if that first element is a <p>, turn it red.
    The Catch: If the very first element inside your article is an <h1> or an <img>, this selector fails entirely and nothing turns red. 
    It does not skip the headline to find the first paragraph; it strictly checks if the absolute first child is a paragraph.

    - Group 2: The Type Specialists (:first-of-type and :nth-of-type(1))
    These two selectors also do the exact same thing as each other.
    When you write article p:first-of-type (or nth-of-type(1)), you are telling the browser:
    1. Look inside the <article>.
    2. Filter out everything that isn't a <p> tag.
    3. Find the very first <p> tag in that filtered list and turn it red.
    The Benefit: It doesn’t matter if your article starts with an <h1>, an <img>, and a <div>. 
    This selector will gracefully skip past them until it hits the first actual paragraph.

  1. Universal selector: * (Wild Card)
  2. Type selector: A type selector matches a HTML element directly.
  3. Class selector:  
    Example:.my-class {
              color: red;
            }
  4. ID selector:
    Example: #rad {
              border: 1px solid blue;
            }
  5. Attribute selector: 
    <div data-type="primary"></div>
    <div data-type="secondary"></div>
    Example: [data-type='primary'] {
              color: red;
            }
            [data-type] {
              color: red;
            }
            s for case-sensitivity
            i for case-insensitivity
            [data-type="primary" s] {  
              color: red;
            }
    Along with case operators, you have access to operators that match portions of strings inside attribute values.
    [href*='example.com'] = /* A href that contains "example.com" */
    [href^='https'] = /* A href that starts with https */
    [href$='.com'] = /* A href that ends with .com */
  6. Grouping selectors: A selector doesn't have to match only a single element. You can group multiple selectors by separating them with commas
    Example: strong,
              em,
              .my-class,
              [lang] {
                color: red;
              }

  7. Pseudo-classes
  - CSS provides useful selector types that focus on specific platform state, like when an element is hovered, structures inside an element,
   or parts of an element.
   Example: /* Our link is hovered */
          a:hover {
            outline: 1px dotted green;
          }

          /* Sets all even paragraphs to have a different background */
          p:nth-child(even) {
            background: floralwhite;
          }
  8. Pseudo-element
  - Pseudo-elements differ from pseudo-classes because instead of responding to the platform state, they act as if they are inserting a 
    new element with CSS. Pseudo-elements are also syntactically different from pseudo-classes, 
    because instead of using a single colon (:), we use a double colon (::).
    ::before, ::after, ::maker, ::selection
    Example: .my-element::before {
              content: 'Prefix - ';
            }

  9. Complex selectors
    Combinators:
      - A combinator is what sits between two selectors. For example, if the selector was p > strong, the combinator is the > character. 
      The selectors which use these combinators help you select items based on their position in the document.
      a. Descendant combinator (space):
      - A descendant combinator allows us to target a child element. This uses a space () to instruct the browser to look for child elements.
      - The Rule: A B
      - What it means: Target element B if it lives anywhere inside element A. It doesn't matter if it's a direct child, a grandchild,
        or a great-grandchild.
        Example: p strong {
            color: blue;
          }
      b. Next sibling combinator (+)
      - You can look for an element that immediately follows another element by using a + character in your selector.
      - The Rule: A + B
      - What it means: Target element B only if it is the exact next sibling (neighbor) directly following element A. 
        They must share the same parent, and B must come immediately after A.
      Example: .top * + * {
              margin-top: 1.5em;
            }
      c. Subsequent- sibling combinator (~):
      - The Rule: A ~ B
      - What it means: Target all element Bs that follow element A, as long as they share the same parent.
       They don't have to be right next to each other; they just have to come somewhere down the line.
      d. Child Selector (>):
      - The Rule: A > B
      - What it means: Target element B only if it is a direct, immediate child of element A. 
        If it gets wrapped inside any other tag, the connection breaks.
    
  10. Compound selectors:
      Example: a.my-class {
                color: red;
              }
