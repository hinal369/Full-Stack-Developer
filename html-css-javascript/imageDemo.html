Responsive Images Guide

Resize your browser window to see how the browser chooses different image file resolutions or aspect ratios dynamically.

Method 1: The <img> Tag with srcset

The browser automatically picks the best size file based on the screen width and pixel density.

Method 2: The <picture> Element

This explicitly forces the browser to shift images at specific media queries. In this case, it loads a square close-up on small screens, and a wide shot on larger screens.
